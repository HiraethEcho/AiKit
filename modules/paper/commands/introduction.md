# Command: introduction

来源：research-writing-skill #24 (github.com/alfonso0512/research-writing-skill)，改编（数学）

## 变量

- `{{text}}`：主定理 + 证明梗概
- `{{lit}}`：相关工作笔记/Zotero keys

## 规则

- 结构：动机 → 历史背景（已知结果 + 引用）→ 主定理精确陈述 → 证明策略概览 → 次要结果 → 组织段
- 历史归因明确（"Following [Author, Year]"）；不虚构文献
- 引言宣称 ↔ 正文交付一致（防 overclaim）

## 输出

- Introduction 草稿 + 引用清单（待 citation-check 核实）
