# Command: abbrev-check

来源：research-writing-skill #10 (github.com/alfonso0512/research-writing-skill)，改编（数学）

## 变量

- `{{text}}`：全稿

## 检查

- 缩写首次出现处定义（如 "MMP (minimal model program)"）
- 无定义即用、重复定义、定义与用不一致
- 数学记号缩写（$K_X$、$\mathrm{NS}(X)$ 等）在 Notation 节或首次使用处声明
- 与 notation-consistency 记号表交叉核对

## 输出

- 缩写表：`缩写 / 全称 / 定义位置 / 问题`
- 未定义缩写单独列出
