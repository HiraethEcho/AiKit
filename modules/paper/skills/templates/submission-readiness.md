# Submission Readiness

来源：AI4Math paper-writing (github.com/andkhalov/AI4Math)，改编。

## Build

- [ ] `latexmk -pdf` 零错误（警告全列）
- [ ] 无 undefined reference / citation
- [ ] 无重复 label

## Source Package

- [ ] 源码树自包含（类/宏包/bib/图齐）
- [ ] 无绝对路径、无外部依赖
- [ ] 图矢量，caption 独立可读

## Evidence

- [ ] 未支撑/存疑内容已在文中显式标注
- [ ] 引用全部核实（citation-check）

## Venue/arXiv

- [ ] 目标期刊类约束满足
- [ ] arXiv 兼容（禁 \include 外部路径等）
- [ ] 版权/许可无冲突

## AI 披露

- [ ] AI 贡献表述事实性、谦逊（acknowledgments/limitations）
