description: Design a new agent persona, skill, or command
---

Invoke the design-agents skill.

Begin by understanding what the user wants to author:
1. Is this a **persona** (role/lens), a **skill** (repeatable workflow), or a **command** (entry point)?
2. The one-sentence purpose and when it should be invoked
3. The framework or steps — dimensions evaluated (persona), ordered workflow (skill)
4. Explicit non-goals and scope limits
5. Output shape — what a typical invocation should produce

Then scan the target location for overlap, draft the artifact, verify against conventions, and confirm with the user before writing.
