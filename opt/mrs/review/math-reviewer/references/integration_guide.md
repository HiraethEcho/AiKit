# Pipeline Usage Example

```
User: I want to write a paper about the Langlands correspondence, from research to submission

Step 1: math-deep-research -> Research report
Step 2: math-paper -> Paper first draft
Step 3: integrity check -> 100% verification of references/data
Step 4: math-reviewer (full) -> 5 review reports + Revision Roadmap
Step 5: math-paper (revision) -> Revised manuscript
Step 6: math-reviewer (re-review) -> Verification review
Step 7: (if needed) math-paper (revision) -> Second revised manuscript
Step 8: integrity check (final) -> Final 100% verification
Step 9: math-paper (format-convert) -> Final paper
```
