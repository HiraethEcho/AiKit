# Command: cover-letter

来源：research-writing-skill #27 (github.com/alfonso0512/research-writing-skill)，改编（数学）

## 变量

- `{{title}}`：论文标题
- `{{results}}`：主贡献
- `{{venue}}`：目标期刊
- `{{novelty}}`：与已有文献的区分

## 规则

- 结构：投稿意图 → 贡献（2-3 条，数学上可验证）→ 与已有工作区分 → 相关性声明
- 贡献描述与摘要/引言一致；不夸大
- 与文献区分具体（引用真实存在的结果）

## 输出

- Cover letter（一页内）
