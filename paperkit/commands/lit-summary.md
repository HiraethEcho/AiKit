# Command: lit-summary

来源：research-writing-skill #18 (github.com/alfonso0512/research-writing-skill) + texra literature-search，改编（数学）

## 变量

- `{{topic}}`：主题/问题
- `{{sources}}`：Zotero keys 或文献列表
- `{{depth}}`：速览 | 综述级

## 规则

- 项目惯例：检索文献优先 zotero
- 一手来源优先；preprint 与已发表区分
- 数学内容：提取定理陈述 + 证明技术 + 记号，不只摘要转述
- 引用精确（arXiv ID/DOI/定理号）

## 输出

- 文献总结（按主题/技术分组）+ 引用清单
