# pi-board

黑板工作区（Blackboard workspace）—— pi 插件，零依赖（只用 Node 内置模块）。

你站在一块和模型共享的黑板前：把**项目文件**和**模型历史消息**钉到板上，在原文上做**精确选区注释**，或对文件做**直接编辑**，然后一键**生成 prompt 并发送**给模型。

## 前端（三栏）

```
┌──────────────────────────────────────────────────────────────┐
│ ◧  顶栏: pi-board [N项·N注释·N已编辑]   状态(中间)   刷新 Clear ☀️/🌙  ◨ │
├──────────────┬────────────────────────────┬─────────────────┤
│ 来源 tabs     │ 头行: prompt · Raw/Preview/Edit │ 注释栏            │
│  板|文件|历史  │      (prompt 模式: 刷新 prompt·发送)│ 添加注释(选中后) │
│  - 文件树     │  prompt: 上=完整 prompt      │ - 注释(点击定位  │
│  - 路径快速打开│          下=追加内容         │    编辑/删除)    │
│  - 路径快速打开│  （Edit 仅文件：生成 diff，不写盘）│                 │
│  - 消息列表    │                            │                 │
│    (git-log  │                            │                 │
│     新在上)   │                            │                 │
└──────────────────────────────────────────────────────────────┘
```

- **左栏/右栏开关**：顶栏最左的 ◧ 收起/展开左栏，最右的 ◨ 收起/展开右栏；按钮高亮（蓝色填充）= 该栏可见。窗口宽度 ≤ 1100px 时两栏默认收起，中间查看区占满；此时点图标可固定展开。选择存于 `localStorage`（键 `pi-board-rails`），清掉该键即恢复「跟随窗口宽度」。
- **查看器 Raw**：行号 gutter + 注释**高亮**（已注释的原文区间有底色）；选区在这里发生。
- **Preview**：只读 markdown 渲染（sandbox iframe），不可选。
- **Edit**（仅文件）：编辑内容不写盘；「保存」仅生成 diff，「撤销」清除 diff。改动以 **diff** 形式随 prompt 发给模型。
- **prompt**：中栏左上角的 `prompt` 按钮，在中栏内切换「查看器 ↔ prompt 面板」。按钮高亮 = 面板可见。再点一次按钮、或点左栏的文件/历史即回到查看器。切到 prompt 后，中栏头行右侧的 `Raw/Preview/Edit` 换成 `刷新 prompt` / `发送`（同一行，不另起一行）。面板分上下两栏：上为完整 prompt（可手动修改），下为**追加内容**（单独编辑、不会被刷新覆盖）。点「发送」回传给模型。
- **注释栏**：右侧栏顶部输入新注释，下方列出当前条目的注释，可**编辑/删除**。
- **左侧 tabs**：板 / 文件 / 历史 —— 只切换左栏内容；点任意 tab，中栏回到查看器。
- **history**：git-log 风格，新消息在上。
- **history 自动刷新**：客户端每 2s 轮询 `/state`，只在历史列表真的变化时重绘「历史」列表；查看器内容、Edit 未保存内容、Raw 滚动位置都不受影响。服务器在 pi 的 `turn_end`（一条回复完成）后重建历史，所以在终端里直接回答也会自动出现（无需点「刷新」）。
- **状态**：状态消息显示在顶栏中间。
- **刷新**：重新拉取全部状态（板项 + 注释 + 历史 + 追加内容）。只等新回复不需要点它，见「history 自动刷新」。
- **Clear**：清空整块板。

## 核心概念

- **上板**：打开文件 / 历史消息 → 手动上板（pin）；注释或编辑的内容也会保留在板上。
- **注释**（仅 comment）：在 Raw 或 Edit 选中文本 → 注释该区间；不选中 → 注释整个文件/消息。注释在右侧栏填写。
- **编辑**（仅文件）：Edit 模式编辑内容不写盘；保存后生成 diff 随 prompt 发给模型；撤销清除 diff。保存编辑时注释会自动重锚（按 quote 重新定位）。
- **prompt**：整块板 → 紧凑自包含文本。按 `# reply` / `# file` 分组；注释内联在条目下；文件只有有注释才输出 `### comments`，有区域注释才输出 `### content`，有编辑则输出 `### diff`（含 `apply following diff`）；只保留 snippet 一种截取方式。历史消息（reply/prompt）**仅在有注释时**、文件**仅在有注释或编辑时**才出现在 prompt 里。追加内容在 prompt 面板下方单独编辑，发送时自动附到末尾。

## 启动

```bash
pi -e /path/to/pi-board          # 或 pi install /path/to/pi-board
```

服务器不随扩展自动启动；运行 `/board` 后启动（绑定 `127.0.0.1`，端口取 `PI_BOARD_PORT`，默认随机），终端打印：

```
[board] port=NNNNN
[board] url=http://127.0.0.1:NNNNN/
```

浏览器打开该 URL。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/board` | 打开板（起服务器 + 开浏览器） |
| `/board refresh` | 刷新历史 + 停止服务器 + `ctx.reload()` 热重载扩展（total refresh） |
| `/board stop` | 停服务器 |
| `/board help` | 显示用法 |

> `/board` 子命令支持 Tab 补全：`refresh` / `stop` / `help`。

> 不自动上板。只有手动打开，或带注释/编辑的内容会保留在板上。

## 状态文件

`<cwd>/.pi/board.json`（原子写 + `.bak`；无 cwd 回退 `~/.pi/board/board.json`）。

## 手动测试（验收要点）

1. 打开 URL → 左栏「文件」tab 出现文件树（点 `src/` 展开）、「历史」tab 列出消息（新的在上）。
2. 点文件 `src/foo.ts` → 查看器 Raw 显示带行号的内容 → 选中一段 → 填注释 → 添加 → **原文区间高亮**，右栏出现该注释。
3. 点注释栏里的注释 → 查看器自动选中对应原文；点「编辑/删除」可改可删。
4. 切 Edit 编辑内容 → 保存 → 磁盘不变，「prompt」面板能看到 diff + `apply following diff` → 撤销清除 diff。
5. Edit 模式下选中文本 → 右侧栏填注释 → 保存编辑后注释行号自动重锚。
6. 点中栏 `prompt` 按钮 → 看到整块板 prompt 文本 → 下方「追加内容」单独填写 → 修改 prompt → 点「发送」→ 模型收到修改后文本 + 追加内容。
7. 发送后注释/追加清空，模型回复自动刷新进历史（新的在上）。
8. 刷新页面 → 板状态还在。

## 已知边界（v1）

- 浏览器 Raw ≤512KB；文件读取 ≤2MB。
- 文件树：不显示隐藏文件、不做自动刷新/重命名/搜索，禁止 symlink 逃逸。
- 注释只有 `comment`（无 question/highlight/todo）。
- Preview 不渲染 LaTeX/Mermaid/表格/图片。
